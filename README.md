# Тестирование модулей авторизации и регистрации

## Описание проекта

В данном проекте реализовано модульное тестирование модулей **авторизации** и **регистрации пользователей** с использованием проекта модельного тестирования в среде разработки **Visual Studio**.

Тестирование проверяет корректность работы методов:

* `Auth()` — авторизация пользователя
* `Reg()` — регистрация пользователя

Также проверяется корректность обработки ошибок при неверных входных данных.

# Реализованные тесты

## Тесты авторизации

### 1. AuthTest

Проверяет авторизацию с некорректными данными.

---

### 2. AuthTestSuccess

Проверяет успешный вход пользователя с корректными логином и паролем.

---

### 3. AuthTestFail

Проверяет негативные сценарии:

* пустые поля
* неверный логин
* неверный пароль

---

## Тесты регистрации

### 4. RegisterTest

Проверяет успешную регистрацию нового пользователя.

Проверяет ошибки при регистрации:

* пустые поля
* уже существующий пользователь
* некорректные данные

---

# Вывод о проведенном тестировании

В ходе тестирования были проверены основные сценарии работы системы:

✔ корректная авторизация пользователей

✔ корректная регистрация новых пользователей 

✔ обработка ошибок при некорректных данных 

✔ защита от входа с неверными учетными данными 

В процессе тестирования были выявлены и исправлены ошибки в логике работы модулей.

После рефакторинга:

* логика авторизации была вынесена в метод `Auth()`
* логика регистрации - в метод `Reg()`

Это позволило корректно протестировать функциональность приложения.

После внесения исправлений все тесты выполняются успешно.

---

# Причина успешного выполнения тестов

Тесты выполняются успешно, потому что:

* метод `Auth()` корректно проверяет логин и пароль пользователя;
* метод `Reg()` корректно добавляет новых пользователей;
* обрабатываются все негативные сценарии (ошибки ввода);
* исключения и проверки работают корректно;
* база данных подключена и используется корректно в тестах.

Это подтверждает правильность реализации модулей авторизации и регистрации.
